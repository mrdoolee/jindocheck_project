# 학급 진도 관리 — 사용자 매뉴얼

이 문서는 교사용 학급 진도/출결/기록 관리 앱의 사용법을 정리한 문서입니다. 앱 내 "사용자 매뉴얼" 버튼(왼쪽 메뉴 하단)에서 보이는 것은 이 문서의 요약본이고, 여기에는 스프레드시트 직접 편집 등 더 상세한 내용까지 담았습니다.

## 1. 기본 원칙

- **계정이 필요 없습니다.** 모든 데이터는 지금 이 브라우저(이 기기, 이 브라우저 앱)에만 저장됩니다.
- 다른 기기/다른 브라우저에서는 이 데이터가 보이지 않습니다. 기기를 바꾸거나 브라우저 데이터가 지워질 상황이 걱정된다면 **설정 > 백업**에서 JSON 백업을 받아두세요.
- Google 시트 동기화는 **선택 기능**입니다. 연결하지 않아도 앱의 모든 기능이 정상 동작합니다.

## 2. 시작하기

1. **설정 > 반 관리**에서 학급을 추가합니다.
2. **설정 > 과목 관리**에서 가르치는 과목을 추가합니다(수학, 영어 등). 한 학급에 과목을 1개만 연결할 수도, 2개 이상 연결할 수도 있습니다 — 같은 화면(반 관리)에서 학급 이름 아래의 과목 배지를 눌러 연결합니다.
3. **설정 > 명단 관리**에서 학급을 선택하고, 아래 형식으로 명단을 붙여넣습니다.
   ```
   번호,이름
   1,홍길동
   2,김철수
   ```
   (엑셀에서 번호/이름 두 열을 복사해서 붙여넣어도 탭으로 구분되어 인식됩니다.) 같은 탭에서 학생 번호/이름을 바로 수정하거나 삭제할 수 있습니다.
4. **설정 > 진도표 관리**에서 과목을 선택하고, 그 과목의 진도 항목(단원/차시)을 등록합니다.
5. 왼쪽 메뉴에서 학급 이름을 클릭하면 그 학급의 4개 탭으로 이동합니다. 진도체크 탭에는 그 학급에 연결된 과목마다 진도표가 하나씩 따로 표시됩니다.

## 3. 학급 페이지 4개 탭

| 탭 | 용도 |
|---|---|
| **진도체크** | 날짜를 선택해 그날 어떤 진도 항목을 완료했는지 체크합니다. |
| **출결확인** | 날짜를 선택해 학생별 출결 상태를 입력합니다. "이력보기"로 지난 날짜의 출결을 조회할 수 있습니다. |
| **누가기록** | 학생별 특이사항(누가기록)을 남깁니다. 전체 기록 보기와 학생별 조회, 날짜순/이름순 정렬을 지원합니다. |
| **자리배치표** | 행/열 크기를 조정하고, 학생을 드래그해서 자리를 배치합니다. 배치도를 JSON 파일로 불러올 수도 있습니다. |

학생 추가·삭제는 이 4개 탭이 아니라 **설정 > 명단 관리**에서만 합니다(의도된 설계입니다).

## 4. 백업

**설정 > 백업**에서:
- **내보내기**: 현재 모든 데이터(반/학생/진도표/진도기록/출결/누가기록/자리배치)를 JSON 파일 하나로 내려받습니다.
- **불러오기**: 내보낸 JSON 파일을 다시 앱에 불러와 복원합니다.

정기적으로(예: 학기 중 주 1회) 백업을 받아두는 것을 권장합니다. 특히 Google 시트 연결/해제를 실험해보기 전에는 반드시 먼저 백업하세요.

## 5. Google 시트 동기화 (선택 기능)

**설정 > Google 시트**에서 "구글 계정 연결하기"를 누르면:
- 구글 로그인 동의 화면으로 이동합니다.
- 승인하면 이 계정 전용의 새 스프레드시트가 자동으로 만들어지고("학급 진도 관리 동기화 (연결한 날짜)"라는 이름), 앱 데이터가 그 시트로 자동 동기화되기 시작합니다.
- 이후 앱을 열어둔 동안 변경 사항이 자동으로 동기화됩니다(로컬 변경 후 약 4초 뒤, 그리고 10초마다 반복 확인). "지금 동기화" 버튼으로 바로 동기화할 수도 있습니다.

**연결 해제**를 누르면 구글 계정 접근 권한 자체가 회수됩니다. 이후 다시 연결하면 **완전히 새로운 스프레드시트**가 만들어집니다 — 이전 시트는 구글 드라이브에 그대로 남아있지만 더 이상 이 앱과 연결되지 않습니다(구글 드라이브에서 직접 열어보거나 정리할 수 있습니다).

### 5.1 스프레드시트를 직접 열어봤을 때 — 탭/열 설명

시트에는 앱의 데이터 종류별로 탭이 하나씩 있습니다. 각 탭의 열(컬럼) 의미는 아래 표와 같습니다.

**과목 기능 이전에 이미 연결해둔 시트라면**: subjects/classSubjects 탭이 없거나 curriculum 탭의 열 구성이 예전 그대로일 수 있습니다. 이 경우 다음에 "지금 동기화"(또는 내보내기/불러오기)를 누르면 서버가 자동으로 빠진 탭을 만들어줍니다 — 하지만 curriculum 탭의 열(예전엔 subjectId 없이 5개 열)은 **내보내기를 한 번 해야** 새 구성(6개 열)으로 갱신됩니다. 탭 구성이 안 맞은 채로 먼저 "불러오기"를 누르면 "헤더가 예상과 다릅니다" 오류가 뜨니, 이런 시트는 처음 한 번은 내보내기부터 하세요.

**중요**: `id`로 끝나는 열(`id`, `classId`, `studentId`, `subjectId`, `curriculumItemId`)은 데이터끼리 서로 연결하기 위한 내부 참조 번호입니다. 이 값을 실수로 바꾸면 학생이 다른 반으로 옮겨지거나, 기록이 엉뚱한 학생 것으로 바뀌는 등의 문제가 생길 수 있습니다. **이 열들은 손대지 마세요.** 새 행을 시트에서 직접 추가하는 것도 권장하지 않습니다 — 새 반/학생/기록 추가는 항상 앱에서 하세요. 시트에서 안전하게 고쳐도 되는 것은 아래 표에 "직접 수정 가능"이라고 표시한 열들뿐입니다.

### 5.2 동기화 관련 주의사항

- 동기화는 **자동으로 일어나지 않습니다.** 설정 > Google 시트에서 "내보내기"(이 기기 → 시트) 또는 "불러오기"(시트 → 이 기기) 버튼을 직접 눌러야 반영됩니다.
- 두 버튼 모두 **전체 교체**입니다. "내보내기"를 누르면 시트의 기존 내용이 이 기기의 데이터로 완전히 대체되고, "불러오기"를 누르면 이 기기의 데이터가 모두 삭제되고 시트의 내용으로 교체됩니다 — 되돌릴 수 없으니 방향을 확인하고 누르세요.
- 여러 기기를 함께 쓴다면, 한 기기에서 작업을 마친 뒤 "내보내기"를 누르고, 다른 기기에서 작업을 시작하기 전에 먼저 "불러오기"를 눌러 최신 상태를 받아오는 습관을 들이세요. 두 기기에서 동시에 각자 새로운 내용을 만들고 있었다면, 나중에 "내보내기"한 쪽의 데이터로 시트가 대체되니 주의하세요.
- 동기화가 "실패" 상태로 표시되면, 설정 > Google 시트에서 다시 "내보내기"/"불러오기"를 눌러보세요. 그래도 안 되면 연결을 해제했다가 다시 연결해보되, **연결 해제 전 반드시 백업을 받아두세요.**
- 연결을 해제했다가 다시 연결하면 매번 새 스프레드시트가 만들어집니다. 예전에 쓰던 시트를 계속 쓰고 싶다면, 설정 > Google 시트의 **"다른 스프레드시트 선택"** 버튼으로 내 Drive에서 그 시트를 직접 골라 연결할 수 있습니다.

## 6. 시간표 (선택 기능)

왼쪽 메뉴의 "🕐 시간표"에서 시간표를 볼 수 있습니다. **설정 > 시간표 설정**에서 두 가지 방식 중 하나를 고릅니다.

### 6.1 컴시간알리미 사용

학교가 컴시간알리미(comci.net)를 쓰는 경우입니다.

- 설정 > 시간표 설정에서 "컴시간알리미 사용"을 선택하고, 학교코드를 입력해 "교사 목록 불러오기"를 눌러 본인 이름을 찾아 저장하세요.
- "시간표" 페이지를 열면 저장해둔 교사의 주간 시간표가 기본으로 뜨고, 그 아래 "학급 시간표 조회"에서 학년/반을 골라 다른 학급의 시간표도 바로 볼 수 있습니다.
- 자동으로 새로고침되지 않습니다 — 최신 상태를 보려면 "새로고침" 버튼을 누르세요.
- 이 기능은 컴시간알리미가 공개로 제공하는 정보를 그대로 가져오는 것으로, 계정 연결이나 로그인이 필요 없습니다. 다만 컴시간알리미 쪽 서비스 구조가 바뀌면 이 기능도 영향을 받을 수 있습니다.

### 6.2 직접 입력

학교가 컴시간알리미를 쓰지 않는 경우, "직접 입력"을 선택하면 요일×교시 표가 나타납니다.

- "교시 수"로 표에 보일 교시 개수를 정하고, 각 칸에 과목과 비고(반/장소 등)를 입력하세요. 칸을 비워두면 그 시간은 빈 시간으로 표시됩니다.
- 입력한 내용은 왼쪽 메뉴의 "시간표"에서 바로 확인할 수 있습니다(컴시간 모드와 달리 학급 시간표 조회는 없습니다 — 다른 반의 시간표를 알려주는 외부 데이터가 없기 때문입니다).
- **직접 입력한 시간표는 실제 콘텐츠로 취급되어 로컬 백업과 Google 시트 동기화 대상에 포함됩니다** (아래 5.1절의 `timetableEntries` 탭 참고). 반면 "컴시간알리미 사용/직접 입력" 모드 선택 자체와 교시 수는 기기별 설정이라 동기화되지 않습니다 — 여러 기기를 쓴다면 각 기기에서 모드를 따로 선택해야 합니다.

## 7. 문의/문제 발생 시
